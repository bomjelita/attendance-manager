# Менеджер учёта посещаемости

**Программный модуль для автоматизации учёта посещаемости студентов учебной группы.**

---

## Описание

«Менеджер учёта посещаемости» — это консольное приложение, разработанное для автоматизации рабочих процессов старост учебных групп ГБПОУ НСО «НППК». Модуль позволяет оперативно фиксировать пропуски, вести список группы и формировать сводную статистику.

### Основные возможности
- Ведение списка студентов группы (добавление, удаление).
- Фиксация пропусков с указанием даты и количества часов.
- Просмотр сводной статистики по группе (сортировка по убыванию пропусков).
- Просмотр детальной истории пропусков по отдельному студенту.
- Автоматическое сохранение данных в файл JSON.

---

## Архитектура

Модуль реализован по принципу многоуровневой архитектуры с разделением ответственности:

- `data_manager.py` — компонент управления данными (чтение/запись JSON).
- `attendance_logic.py` — компонент бизнес-логики (обработка пропусков).
- `ui_module.py` — компонент пользовательского интерфейса (консольное меню).
- `main.py` — главный файл запуска.

---

## Требования

- Python 3.8 или выше.
- Операционная система: Windows 10/11, Linux.
- Внешние зависимости: отсутствуют (используется только стандартная библиотека).

---

## Установка и запуск

1. Скачайте или клонируйте репозиторий:
   git clone https://github.com/bomjelita/attendance-manager.git
2. Перейдите в папку проекта:
   cd attendance-manager
3. Запустите программу:
   python main.py
